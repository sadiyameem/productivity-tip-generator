# Productivity Tip Generator

# Description
- This is a simple project that can help someone become more productive. The user will click the button to receive a tip and the results of that tip.

# Features
- Random tip by the click of the button
- The same tip won't appear twice in a row
- Includes different productivity techniques

# Tools Used
- HTML
- CSS
- JavaScript
- https://colormagic.app/shades/light-lavender
- https://clickup.com/blog/productivity-hacks/
- https://emojicopy.com/

# Challenges/Learned
- I learned how to prevent the same tip from appear and how to generate random tips by using Math.random() and Math.floor().
- A challenge will making it look simple and clean without adding extra stuff.
